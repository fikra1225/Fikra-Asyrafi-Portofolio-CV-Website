Pivot Table

How to build a real, refreshable native PivotTable instead					
1. Click any cell inside the Cleaned_Data table.					
2. Insert tab -> PivotTable -> New Worksheet -> OK.					
3. Drag 'Category' into ROWS.					
4. Drag 'AnnualSalary' into VALUES three times, then set each to Count, Average and Max (right-click a value -> Value Field Settings -> Summarize by).					
5. Drag 'Company' into FILTERS to let anyone slice the pivot by a single employer.				
6. Right-click any value cell -> Number Format -> Currency, no decimals, for the salary columns.		
7. Insert tab -> PivotChart, to add a linked chart that updates whenever the pivot refreshes.			
8. After editing Cleaned_Data, right-click the pivot -> Refresh (or PivotTable Analyze -> Refresh) to pull in changes.	

What If Analysis
Note: these rows use ordinary formulas so the file recalculates outside Excel too. For the portfolio, replace them with a genuine Excel Data Table: put the raise-% list in column B, put '=D8*(1+row input)' logic in one formula cell linked to D8's row/column, select B10:C17, then Data tab -> What-If Analysis -> Data Table -> Column input cell = the raise-% input -> OK. Excel then fills the array with {=TABLE(,cell)}.

Goal Seek
Steps: Data tab -> What-If Analysis -> Goal Seek.						
  Set cell:      D27  (New Annual Salary)						
  To value:      the number in D25 (Target Annual Salary)						
  By changing:   D26  (Required Raise %)						
Click OK — Excel iterates the raise % until the new salary matches the target.	

Scenario Manager
Steps: Data tab -> What-If Analysis -> Scenario Manager -> Add.						
Scenario name: Conservative | Changing cells: D26 | value 2%.  Repeat for Moderate (5%) and Aggressive (10%).						
Click 'Summary' to generate a Scenario Summary report showing the resulting New Annual Salary for each case.

Macro VBA
Setup steps						
1. Open this workbook in Excel (Windows or Mac).						
2. File -> Save As -> choose 'Excel Macro-Enabled Workbook (*.xlsm)' and save.						
3. Press Alt+F11 to open the VBA editor.						
4. Right-click the workbook in the Project pane -> Insert -> Module (repeat for each of the 3 macros above, or paste all into one module).						
5. Paste the corresponding Sub...End Sub code into each module.						
6. Close the VBA editor. Press Alt+F8, select CleanAndConvertSalaries, click Run - Cleaned_Data will be rebuilt from Raw_Data.						
7. Run GenerateSummaryReport the same way to create the Auto_Summary sheet.						
8. To make this a one-click experience: go to Dashboard, Insert tab -> Shapes -> draw a button/rectangle, right-click it -> Assign Macro -> pick RefreshDashboard (repeat for FilterDashboardByCompany).						
9. Save the .xlsm. Every time you reopen it, click 'Enable Content' on the yellow security bar to allow the macros to run.
