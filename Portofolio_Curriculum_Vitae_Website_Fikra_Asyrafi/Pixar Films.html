📋 Project Overview

Every Pixar theatrical release from Toy Story (1995) to Inside Out 2 (2024) was loaded into a PostgreSQL database as six normalized tables and joined together to explore how box office results, critical reception, and awards recognition have evolved across three decades of the studio's history.

The goal was to practice real relational database design and analytical SQL — not just SELECT * queries, but multi-table joins, common table expressions (CTEs), window functions, and string aggregation to turn flat CSV exports into a queryable, insight-ready data model.

  • Data Source: Pixar Films dataset (films, people, genres, box office, public response, academy awards)
  • Database: PostgreSQL, tables linked on the film title as the shared key
  • Query Techniques: INNER/LEFT JOIN, CTEs, RANK() & SUM() OVER(), STRING_AGG, CASE, ROUND
  • Focus Areas: Box office & ROI, critical vs. audience reception, Academy Awards, genres & crew

Under the Hood

Techniques & Methods Applied

The SQL and relational database skills demonstrated across all 14 queries in this project.

Multi-Table Joins

INNER and LEFT JOIN across up to five tables on the shared film key to build the full scorecard view.

Common Table Expressions

CTEs to stage intermediate aggregations before final ranking and filtering, keeping queries readable.

Window Functions

RANK() OVER() for ROI ranking and SUM() OVER (ORDER BY release_date) for cumulative box office.

Aggregate Functions

COUNT, SUM, AVG, and ROUND to compute totals, decade trends, and win rates.

String Aggregation

STRING_AGG() to collapse repeated crew roles and film lists into single readable rows.

Conditional Logic

CASE WHEN expressions to bucket films into decades and classify award outcomes.

NULL Handling

Graceful handling of missing budget data (e.g. Luca) so incomplete rows don't break ROI calculations.

Percentage & Ratio Calculations

Derived fields like ROI %, award win rate, and normalized critic–audience score gaps.

Data Modelling

Designed a clean six-table relational schema from flat CSV exports, ready for repeatable analysis.
