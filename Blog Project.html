Full-Stack Web Development

Blog Capstone Project

A full-stack blog web application built using Node.js, Express, and EJS. It features a responsive UI, robust backend routing, and persistent JSON storage for managing blog posts.

💻 Node.js 🚀 Express 📄 EJS 📈 HTML & CSS

Project Overview

This project demonstrates the ability to build and deploy a dynamic web application from scratch. The focus was on creating a clean, user-friendly interface while ensuring solid backend logic and data persistence.

Key Features

  • RESTful Routing: Implemented comprehensive GET and POST routes for creating, viewing, editing, and deleting blog posts.
  • Dynamic Views: Used EJS templating engine to render data dynamically on the frontend.
  • Persistent Storage: Designed a file-based storage system using posts.json and the node:fs module to ensure data persists across server restarts.
  • Form Validation: Integrated robust server-side validation to ensure all posts have titles, authors, and content before being saved.
